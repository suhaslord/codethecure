Public images. Explicit provenance.

GainGuard uses BreastMNIST from MedMNIST, derived from the breast-ultrasound dataset by Al-Dhabyani and colleagues. The 64 × 64 release contains 780 grayscale images. We preserve its official split: 546 training, 78 validation and 156 test images.

The official binary mapping is 0 = malignant, 1 = normal / benign. Normal and benign are merged; the model cannot distinguish them. Test labels include 42 malignant and 114 normal/benign images. Samples are images, not verified independent patients.

Data: MedMNIST+ on Zenodo, CC BY 4.0. Citations: Yang et al., Scientific Data 10, 41 (2023), doi:10.1038/s41597-022-01721-8; Al-Dhabyani et al., Data in Brief 28, 104863 (2020), doi:10.1016/j.dib.2019.104863. Displayed images are resized for viewing; no detail beyond the 64 × 64 input is recovered.

A small, inspectable baseline.

The network has three convolutional layers, adaptive pooling and a two-class head. Input pixels are divided by 255. Training uses AdamW, batch size 32, learning rate 0.001 and weight decay 0.01, without augmentation or pretraining. The checkpoint with the lowest validation cross-entropy is selected from 60 epochs. The test set is never used for model selection.

Temperature scaling divides logits by a positive scalar. A fixed 0.5–4.0 grid (141 candidates) minimizes validation negative log-likelihood. It changes probabilities, not the predicted class. Model selection and temperature fitting share the small validation set; calibration can overfit.

Binary Brier score uses malignant-class probability. ECE uses 10 equal-width bins of maximum class probability. AUROC treats malignant as the positive class and gives ties half credit. Accuracy intervals use the Wilson method at 95%; they ignore image clustering and training variance.

Change the pixels, hold the model fixed.

Gain: multiply normalized intensity by 10dB/20. Speckle proxy: multiply intensity by (1 + σZ), with Z drawn from a seeded standard normal. Shadow proxy: apply a depth-increasing Gaussian attenuation column centered at 55% of image width. Clip to [0, 1], then round to 8-bit pixels.

The benchmark evaluates −3/−6/−9 dB gain, +3/+6/+9 dB gain, σ = 0.15/0.30/0.45 speckle, and 25/50/75% maximum shadow attenuation. The interactive lab also supports combined stresses. Each image uses seed 20261014 + its zero-based test index; the same noise realization is scaled across severity.

These are digital robustness probes, not a validated ultrasound simulator. Real scanner gain often acts in a log-compressed pipeline. Synthetic transforms can remove meaningful features, particularly at high severity. We do not establish label preservation or model real deployment performance.

The Benchmark threshold study separately tunes cutoffs on validation data only, freezes them for test, and plots all 51 confidence cutoffs. Its 50% average validation review budget is a research protocol choice, not a clinical requirement. It reuses the same 78 validation images and was added after the original test report, so the new comparison is exploratory. Live lab flags preserve the original fixed baseline below.

An auditable rule, not a safety guarantee.

An experiment is flagged when any of three conditions holds: calibrated confidence is below 80%; the predicted class differs from the original; or malignant-class probability changes by more than 15 percentage points. The cutoffs are fixed demonstration choices, not optimized on test labels or validated for clinical use.

“Error capture” is the fraction of incorrect predictions sent to review. “Review rate” is the fraction of all images flagged. “Unflagged accuracy” excludes flagged images and must always be read with coverage. The rule can miss confidently wrong predictions that remain stable. A review mark simply records that a researcher inspected a case.

Entropy is binary predictive entropy in bits, ranging from 0 to 1. It describes the distribution of this model’s outputs; neither entropy nor softmax confidence represents the probability that a patient has cancer.

What this prototype does not establish.

    This is a focused application of existing robustness and calibration methods, not a claim to have invented corruption testing. Relevant prior work includes MedMNIST-C and temperature scaling by Guo et al.

    Next experiments: repeated training seeds, patient-grouped external data, real scanner metadata, physically grounded corruptions, validation-selected review budgets and comparison with augmentation-trained models. Clinical decisions require a different study and appropriate expert oversight.
